# HOMR GUI (Music Score to MIDI)

本项目是基于 [liebharc/homr](https://github.com/liebharc/homr) 的 GUI 封装与增强版本。

### 主要改进：
* **可视化界面**：增加了基于 PyQt6 的交互界面，告别命令行。
* **模式切换**：支持 CPU 兼容模式与 GPU 加速模式一键切换。
* **国内优化**：优化了模型下载逻辑，使用镜像代理提升下载速度。
