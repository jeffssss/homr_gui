HOMR GUI (Music Score to MIDI)
本项目是基于 liebharc/homr 的 GUI 封装与增强版本。
主要改进：
• 增加了基于 PyQt6 的可视化交互界面。
• 支持 CPU 兼容模式与 GPU 加速模式切换。
• 优化了国内模型下载速度（使用镜像代理）。
